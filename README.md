# Pielet

Лёгкая библиотека круговых (радиальных) контекстных меню для браузера. Ноль зависимостей, чистый ESM, тёмная тема из коробки.

- Раскладка секторов, hover, hit-testing и поведение при выходе за край экрана — чистая математика без DOM.
- Один открытый runtime на страницу (браузерный паттерн context menu), кросс-экземплярная гарантия «одно меню».
- Стили — только через CSS custom properties, темы переопределяются без копирования библиотечных стилей.
- Отрисовка — DOM + CSS `clip-path`.

## Быстрый старт

```html
<link rel="stylesheet" href="src/styles/pielet.css" />
```

```js
import Pielet from 'pielet.js';

const menu = new Pielet({
  items: [
    { typeContent: 'text', content: 'Открыть', action: () => openFile() },
    { typeContent: 'text', content: 'Сохранить' },
    { typeContent: 'none' }
  ]
});

window.addEventListener('contextmenu', (e) => {
  e.preventDefault();
  menu.open(e.clientX, e.clientY);
});
```

## Использование с CDN (IIFE)

Для страниц без сборщика — готовая IIFE-сборка `dist/pielet.browser.js` (доступна также через [unpkg](https://unpkg.com/pielet) и [jsdelivr](https://www.jsdelivr.com/package/npm/pielet)). Она создаёт глобал `Pielet`; стили подключаются отдельно:

```html
<link rel="stylesheet" href="https://unpkg.com/pielet/dist/pielet.css" />
<script src="https://unpkg.com/pielet/dist/pielet.browser.js"></script>
<script>
  const menu = new Pielet({
    items: [
      { typeContent: 'text', content: 'Открыть' },
      { typeContent: 'text', content: 'Сохранить' }
    ]
  });

  window.addEventListener('contextmenu', (e) => {
    e.preventDefault();
    menu.open(e.clientX, e.clientY);
  });
</script>
```

API идентичен ESM-версии. IIFE-сборка предназначена только для браузера и не экспортируется из пакета как модуль.

## API

| Член | Описание |
| --- | --- |
| `new Pielet(config)` | Создаёт экземпляр. Конфигурация нормализуется и валидируется. DOM не создаётся до `open()`. |
| `menu.config` | Живой объект конфигурации. Изменения применяются при следующем `open()`. |
| `menu.open(x, y)` | Открывает меню с центром в точке viewport (clientX/clientY). Выбрасывает ошибку на нечисловых координатах. |
| `menu.close()` | Плавно закрывает меню. No-op, если меню закрыто. |
| `Pielet.closeAll()` | Статический метод: плавно закрывает открытое меню, не требуя ссылки на экземпляр. No-op, если ни одно меню не открыто. Удобен для глобальных обработчиков (клик мимо меню, `Escape` и т.п.). |
| `menu.setItemContent(id, content)` | Меняет содержимое пункта по его `id` в живом открытом меню. Тип нового содержимого должен совпадать с `typeContent`, заданным при создании (сменить тип нельзя). Обновляет DOM и `config.items[i].content`. Бросает ошибку, если меню закрыто, `id` не найден, либо тип `content` не подходит. Типичный кейс — вызов из `action` пункта с `keepOpen: true`. |
| События | `open` — `CustomEvent` с `detail: { rect, menu }` (bounding rect видимой части меню + экземпляр); `close` — с `detail: { menu }`; `select` — с `detail: { id, menu, coords }` (id выбранного пункта + экземпляр + координаты клика `{ x, y }`), диспатчатся на экземпляре (`EventTarget`). |
| `menu.config.items[i].action` | Вызывается после полного закрытия меню (DOM и слушатели уже убраны), с тремя аргументами — `id` пункта (строка), экземпляром меню и координатами клика `{ x, y }`. |

Исключения из `action` пробрасываются в консоль (не проглатываются); меню при этом остаётся закрытым и пригодным к переиспользованию.

### Обновление содержимого открытого меню

Пункт с `keepOpen: true` в click-режиме не закрывает меню, поэтому его `action` может перерисовать содержимое «на месте» по `id`:

```js
const menu = new Pielet({
  items: [
    { typeContent: 'text', content: 'Кликни', id: 'status', keepOpen: true, action: (id, menu) => {
      menu.setItemContent(id, 'Обновлено');
    } }
  ]
});
```

`setItemContent` требует открытого меню и строкового/`Node` содержимого, соответствующего `typeContent` пункта (сменить тип нельзя).

## Сабменю

Пункт с `isSubMenu: true` открывает другое меню (`menu`) вместо вызова `action`. `typeContent` и `content` рендерятся как обычно:

```js
const colors = new Pielet({
  items: [
    { typeContent: 'text', content: 'Красный', action: () => setColor('#f00') },
    { typeContent: 'text', content: 'Синий', action: () => setColor('#00f') }
  ]
});

const menu = new Pielet({
  items: [
    { typeContent: 'text', content: 'Цвет', isSubMenu: true, menu: colors },
    { typeContent: 'text', content: 'Сброс', action: () => setColor(null) }
  ]
});
```

- **click-режим**: клик по пункту с `isSubMenu` закрывает меню и открывает сабменю в точке клика. Эмитится `select` (`detail.id` — id пункта), `action` игнорируется.
- **hold-режим**: наведение на пункт с `isSubMenu` в течение `submenuDelay` мс открывает сабменю в точке указателя (без `select` и `action`). Если сабменю тоже в hold-режиме, оно подхватывает зажатую кнопку и работает как обычное меню. Если кнопки меню и сабменю не совпадают — сабменю закроется при первом движении указателя (кнопка не удержана).
- То же hover-поведение работает в click-режиме, пока отслеживаемая кнопка удержана (меню ведёт себя как hold). `submenuDelay: 0` отключает hover-открытие полностью.
- Пункты-сабменю автоматически помечаются индикатором (`submenuIndicator`: дуга у основания, стрелка на внешнем крае кольца или обе). Цвет индикатора настраивается CSS-переменной `--pielet-submenu-indicator`.

## События

Экземпляр реализует `EventTarget`. Все события — `CustomEvent` с `detail.menu` — экземпляром меню, для которого событие вызвано. Событие `open` также несёт `detail.rect` — DOMRect-совместимый bounding rect видимой части меню; `select` несёт `detail.id` — строковый идентификатор выбранного пункта — и `detail.coords` — координаты указателя в момент клика по пункту. Все диспатчатся на самом экземпляре:

```js
const menu = new Pielet({ items: [{ typeContent: 'text', content: 'Открыть' }] });

menu.addEventListener('open', (e) => {
  const { rect, menu } = e.detail;
  console.log('меню открыто и готово к взаимодействию', rect);
});
menu.addEventListener('close', (e) => {
  console.log('меню закрыто и удалено из DOM', e.detail.menu);
});
menu.addEventListener('select', (e) => {
  console.log('выбран сектор с id', e.detail.id, 'в точке', e.detail.coords, 'меню', e.detail.menu);
});
```

Порядок при выборе пункта: `select` → `close` → вызов `action`.

## Конфигурация

| Поле | По умолчанию | Допустимые значения | Описание |
| --- | --- | --- | --- |
| `size` | `240` | любое конечное число `> 0` | Внешний диаметр меню в px (включая кольцо). |
| `centerSize` | `72` | любое конечное число: `> 0` и `< size` | Диаметр центральной dead zone (клик по центру закрывает меню). В центре рендерится инертный div-хук `.pielet__center` (позиция/размер = `centerSize`, `pointer-events: none`, без внешнего вида) — через этот класс можно стилизовать центр меню. |
| `gap` | `4` | любое конечное число `>= 0` | Зазор между секторами в px (не рисуется, если пункт всего один). |
| `startAngle` | `-90` | любое конечное число (в градусах) | Угол первого сектора (правый край — 0°, верх — -90°). При одном пункте — угол, на котором центрируется контент. |
| `direction` | `'clockwise'` | `'clockwise'` \| `'counterclockwise'` | Направление раскладки секторов. |
| `interactionMode` | `'click'` | `'click'` \| `'hold'` | Режим взаимодействия. В hold-режиме меню живёт, пока удержана кнопка из `button`. |
| `button` | `'left'` | `'left'` \| `'middle'` \| `'right'` \| `'back'` \| `'forward'` | Отслеживаемая кнопка. Меню выбирает/закрывается только по её отпусканию (и в hold, и в click). |
| `closeDistance` | `48` | любое конечное число `>= 0` | Дополнительный радиус вокруг меню: выход указателя за него закрывает меню. |
| `items` | — (обязательно) | непустой массив объектов `PieletItem` | Пункты меню. |
| `fit` | `'circle'` | `'circle'` \| `'square'` | Как вписывать контент в сектор: `'circle'` — по безопасной окружности (контент не поворачивается, текст всегда горизонтален); `'square'` — по прямоугольному боксу сектора (контент поворачивается вместе с сектором). |
| `unifyText` | `false` | `true` \| `false` | Выровнять шрифт всех `text`-пунктов по наименьшему влезающему размеру (шрифт самого длинного текста). Действует только при `fit: 'square'`, в `'circle'` игнорируется. |
| `submenuDelay` | `400` | любое конечное число `>= 0` | Задержка (мс) открытия сабменю при наведении на пункт с `isSubMenu: true`. Действует в hold-режиме и в click-режиме, пока отслеживаемая кнопка удержана. `0` отключает hover-открытие (остаётся только открытие по клику). |
| `submenuIndicator` | `'both'` | `'arc'` \| `'chevron'` \| `'both'` | Индикация пунктов-сабменю: `'arc'` — дуга у внутреннего радиуса сектора (основание), `'chevron'` — стрелка на внешнем крае кольца, направленная радиально наружу, `'both'` — и то и другое. Варианта без индикации нет. Размер шеврона масштабируется с шириной кольца (`min(14px, ringWidth × 0.18)`), центр — за внешним краем на `0.5 × size` (`outerRadius + 0.5·size`), так что он остаётся радиально дальше контента и не сливается с ним при любом `size` и `fit`. |
| `availableArc` | — (полный круг) | непустой массив имён частей дуги | Ограничивает дугу, по которой распределяются пункты. Части (0° = право, 90° = низ): половины `'right'` \| `'bottom'` \| `'left'` \| `'top'` и четверти `'top-right'` \| `'bottom-right'` \| `'bottom-left'` \| `'top-left'`. Объединение должно быть одной сплошной дугой (пересечения и полный круг допустимы, разрывы — ошибка). У краёв viewport дуга сдвигается/отзеркаливается в свободную часть экрана, при нехватке места — сужается до наибольшей видимой дуги, а радиус масштабируется так, чтобы площадь видимой дуги не уменьшалась. |

### PieletItem

| Поле | Допустимые значения | Описание |
| --- | --- | --- |
| `typeContent` | `'text'` \| `'image'` \| `'node'` \| `'none'` | Тип содержимого. `'none'` — пустой (некликабельный и неhover-ящийся) сектор-разделитель. |
| `content` | для `'text'` и `'image'` — непустая строка; для `'node'` — DOM `Node` (например, `SVGElement`); для `'none'` — не требуется | Содержимое сектора. |
| `id` | непустая строка (опционально); если не указан — генерируется автоматически при каждом `open()` в формате `pielet-<время>-<n>` (префикс `pielet-` зарезервирован) | Идентификатор пункта. Передаётся в `select` (`event.detail.id`) и первым аргументом в `action` (вторым — экземпляр меню, третьим — координаты клика `{ x, y }`). |
| `action` | функция `(id, menu, coords) => {}` (опционально) | Вызывается при выборе пункта. Аргументы: `id` — идентификатор пункта (строка); `menu` — экземпляр меню `Pielet`; `coords` — объект `{ x, y }` с координатами указателя (clientX/clientY) в момент клика по пункту. Игнорируется при `isSubMenu: true`. |
| `keepOpen` | `true` \| `false` (опционально) | Если `true`, выбор пункта в click-режиме не закрывает меню (`select` и `action` по-прежнему работают). В hold-режиме игнорируется. |
| `isSubMenu` | `true` \| `false` (опционально) | Если `true`, пункт открывает сабменю (`menu`) вместо вызова `action`. Требует `typeContent` не `'none'` и наличие `menu`. `select`-событие при этом по-прежнему эмитится. |
| `menu` | экземпляр `Pielet` (обязателен при `isSubMenu: true`) | Меню, открываемое как сабменю пункта. В click-режиме открывается по клику в точке указателя; в hold-режиме — по наведению через `submenuDelay` мс. |

## Кастомизация темы

Определите переменные до загрузки стилей либо на `:root`, либо на любом родителе (переменные наследуются):

```css
:root {
  --pielet-background: #2d2f36;        /* фон сектора */
  --pielet-background-hover: #43475a;  /* hover-подсветка */
  --pielet-opacity: 0.97;              /* непрозрачность меню */
  --pielet-color: #f2f2f4;             /* цвет текста/иконок */
  --pielet-submenu-indicator: #c9cdd9; /* цвет индикатора сабменю (дуга/стрелка) */
  --pielet-transition-duration: 150ms; /* длительность появления/закрытия */
  --pielet-transition-easing: cubic-bezier(0.2, 0.6, 0.3, 1);
  --pielet-shadow: 0 12px 28px rgba(0, 0, 0, 0.35);
}
```

Все стили ограничены namespace `.pielet` — глобальных правил нет.

## Поведение у края экрана

Если круг меню выходит за границы viewport, пункты перераспределяются по наибольшей непрерывной видимой дуге (край «съедает» недоступные секторы). Чтобы контент пунктов при этом не уменьшался, внешний радиус меню увеличивается: площадь bounding-прямоугольника видимой дуги остаётся равной площади прямоугольника полной дуги (квадрата `2·outerRadius`; для `availableArc` — площади номинального bbox дуги). Радиусы кольца масштабируются пропорционально, форма меню и его центр сохраняются. У «чистого» края (видимая дуга ≥ π — клип одной гранью) рост ограничен: размер меню отклоняется от конфигурации не более чем на 10 px; в углах (видимая дуга < π) лимита нет — площадь сохраняется полностью. Если видимая дуга меньше четверти круга — используется геометрия полного круга без масштабирования. Центр меню никогда не перемещается.

Меню немедленно закрывается при `scroll` (в любом контейнере), `resize` окна и `visualViewport.resize`.

## Требования к браузеру

Любой современный браузер с поддержкой Pointer Events, `clip-path` и CSS custom properties (Chrome/Edge 80+, Firefox 70+, Safari 14+).

## Демо

```bash
npm run dev:demo
```

Откройте http://localhost:5173/demo/, либо смотрите примеры в `docs/examples/`.

В демо наглядно показаны и сабменю с двойной вложенностью: пункт «Цвет» (или 🎨 в circle-режиме) открывает палитру «Основные»/«Пастельные», а выбор цвета меняет `--pielet-background` меню. Задержку hover-открытия сабменю в hold-режиме регулирует контрол `submenuDelay`, а тип индикатора (`both`/`arc`/`chevron`) — `submenuIndicator`.

## Разработка

```bash
npm install       # install
npm test          # unit + integration (vitest)
npm run test:e2e  # end-to-end (Playwright, chromium)
npm run build     # dist/pielet.js (ESM) + dist/pielet.browser.js (IIFE) + dist/pielet.css + dist/*.d.ts
npx vite          # run
```
