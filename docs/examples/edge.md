# Пример: поведение у края экрана (edge reflow)

При открытии у края viewport пункты не обрезаются, а перераспределяются по видимой дуге. Чтобы контент пунктов не становился мельче, меню при этом масштабируется вверх:

```js
import Pielet from 'pielet';
import 'pielet/style.css';

const menu = new Pielet({
  size: 240,
  items: [
    { typeContent: 'text', content: 'Север' },
    { typeContent: 'text', content: 'Восток' },
    { typeContent: 'text', content: 'Юг' },
    { typeContent: 'text', content: 'Запад' }
  ]
});

// Открытие в нижнем правом углу: доступна только усечённая дуга,
// радиус меню увеличивается так, чтобы площадь видимой дуги не уменьшалась.
menu.open(window.innerWidth - 60, window.innerHeight - 60);
```

Правила:
- Центр меню не перемещается — `open(x, y)` фиксирует его (проверяется e2e).
- Полезной дугой считается наибольшая непрерывная видимая дуга внешней окружности.
- Внешний радиус (и пропорционально — внутренний, ширина кольца, средний радиус) увеличивается так, чтобы площадь bounding-прямоугольника видимой дуги равнялась площади прямоугольника полной дуги — квадрата `2·outerRadius`. Для `availableArc` целевая площадь — номинальный bounding box дуги паттерна.
- У «чистого» края (видимая дуга ≥ π — клип одной гранью) рост ограничен: отклонение размера меню от конфигурации не больше 10 px. В углах (видимая дуга < π) лимита нет — площадь сохраняется полностью.
- Если видимая дуга < π/2, используется полная круговая геометрия (как если бы места было достаточно) — без масштабирования.
- Первый сектор переносится в начало выбранной дуги.
