# Пример: поведение у края экрана (edge reflow)

При открытии у края viewport пункты не обрезаются, а перераспределяются по видимой дуге:

```js
import Pielet from 'pielet';
import 'pielet/style.css';

const menu = new Pielet({
  size: 240,
  items: [
    { typeContent: 'text', content: 'Север' },
    { typeContent: 'text', content: 'Восток' },
    { typeContent: 'text', content: 'Юг' },
    { typeContent: 'text', content: 'Запад' }
  ]
});

// Открытие в правом нижнем углу: доступна только дуга ~90°,
// секторы «сжимаются» и выстраиваются вдоль видимой части круга.
menu.open(window.innerWidth - 60, window.innerHeight - 60);
```

Правила:
- Центр меню не перемещается — `open(x, y)` фиксирует его (проверяется e2e).
- Полезной дугой считается наибольшая непрерывная видимая дуга внешней окружности.
- Если видимая дуга < π/2, используется полная круговая геометрия (как если бы места было достаточно).
- Первый сектор переносится в начало выбранной дуги.
