# Миграция

Pielet — новая библиотека, версия 0.1.0. Этот документ описывает различия в подходах, если вы переходите с других круговых меню (примеры: context-menu-библиотеки на DOM-anchor или canvas-рендером).

## Если вы переходите с canvas/SVG-рендера

Pielet рендерит меню DOM + CSS `clip-path`:

- Нет канвас-контекста и `requestAnimationFrame`-циклов отрисовки — нечего инвалидировать.
- Кастомизация — CSS, а не draw-колбэки. Настройки визуала живут в CSS custom properties (`--pielet-*`).
- `menu.element` (корневой `<div class="pielet">`) доступен после `open()` через `document.querySelector('.pielet')` или демо-хук; пиксельные размеры текста/дуг считаются динамически.

## Если вы переходите с anchor/DOM-listeners модели

- Pielet не имеет anchor-системы: никаких «элемент, у которого появилось меню», подписок на DOM-мутации и автопозиционирования.
- Вы сами решаете, **когда** открыть меню (`contextmenu`, `pointerdown` и т.д.) и передаёте координаты: `menu.open(e.clientX, e.clientY)`. Именно поэтому в браузере валидны clientX/clientY — всё поведение меню управляется библиотекой.
- Закрытие не привязано к «событию вне меню» — слушатели на window работают с указателем, скроллом и ресайзом.

## Изменения поведения, которые нужно учесть

| Старое поведение | Pielet |
| --- | --- |
| Несколько открытых меню на странице | Одно открытое меню на страницу (как системный контекстный) |
| `destroy()` / утечка слушателей | `close()` полностью освобождает DOM и слушатели; экземпляр переиспользуется |
| `select`-данные в detail события | `open` несёт `detail: { rect, menu }` — bounding rect видимой части меню и экземпляр меню; `close` несёт `detail: { menu }`; `select` несёт `detail: { id, menu }` — id пункта и экземпляр меню |
| Анимации на JS | CSS transitions; длительность задаётся `--pielet-transition-duration` |
| Своя тема через параметры | CSS variables на любом родителе |

## Чек-лист перехода

1. Импортируйте `Pielet` из 'pielet', стили — из 'pielet/style.css' (опционально).
2. Замените вызовы открытия на `menu.open(x, y)`.
3. Перенесите пункты меню в `items`; иконки — `typeContent: 'node'`/`'image'`.
4. Замените свои draw-стили на переопределение `--pielet-*` переменных.
5. Удалите собственные слушатели скролла/ресайза — Pielet делает это сам.
