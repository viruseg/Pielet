# Changelog

Все версии — фиксированные релизы (no rolling releases).

## Unreleased

**Возможности**

- Сабменю: `PieletItem.isSubMenu: true` + `PieletItem.menu` (экземпляр `Pielet`) открывают другое меню вместо вызова `action`. В click-режиме сабменю открывается кликом по пункту в точке указателя (с `select`-событием, без `action`); в hold-режиме — наведением с задержкой `submenuDelay` (по умолчанию 400 мс, `0` отключает hover-открытие). Hover-открытие действует и в click-режиме, пока отслеживаемая кнопка удержана. Hold-меню, открытое кнопкой, не совпадающей с его `button`, закрывается при движении указателя.
- Демо: добавлен пункт «Цвет» (иконка 🎨 в circle-режиме) с двойной вложенностью сабменю — «Цвет» → палитра → «Основные»/«Пастельные» (выбор цвета меняет `--pielet-background`). Добавлен контрол `submenuDelay` (0–2000 мс). Сабменю следуют за настройками демо (режим/кнопка/задержка), чтобы hold-режим подхватывал зажатую кнопку и во вложенных меню. Открытие меню теперь блокируется проверкой `document.querySelector('.pielet')` — после открытия сабменю клик по его пунктам не переоткрывает главное меню.
- Индикация сабменю: `submenuIndicator: 'arc' | 'chevron' | 'both'` (default `'both'`) — пункты с `isSubMenu` автоматически помечаются дугой у внутреннего радиуса (`'arc'`), стрелкой за внешним краем кольца (`'chevron'`) или обеими. Варианта без индикации нет. DOM: класс `pielet__item--submenu`, элементы `.pielet__submenu-arc` / `.pielet__submenu-chevron` (`aria-hidden`), контент и `fitText` не затрагиваются; цвет — CSS-переменная `--pielet-submenu-indicator`. В демо добавлен селект `submenuIndicator`.

**Исправления**

- Шеврон индикатора сабменю больше не пересекается с контентом ни при каком `fit`. Раньше он сидел внутри кольца и в режиме `fit='square'` накладывался на текст (в демо — на «Цвет»), а в палитре «Основные»/«Пастельные» сливался с подписями. Теперь шеврон целиком вынесен за внешний край кольца (центр на `outerRadius + size × 0.5` по оси `mid`, внутренняя кромка — на внешнем радиусе) и крепится к корню меню, а не к сектору (clip-path сектора срезал бы всё за кольцом). Контент при любом `fit` остаётся внутри кольца, поэтому между ним и шевроном гарантированный радиальный зазор. Позиции контента пунктов-сабменю полностью совпадают с позициями контента обычных пунктов (тест: два одинаковых меню, plain vs submenu); контент и шеврон обоих пунктов палитры лежат на одной горизонтальной линии. Покрыто unit-, интеграционными и e2e-тестами.
- Шеврон индикатора сабменю: размер увеличен в 2 раза (до 28px при стандартном размере меню) и масштабируется с шириной кольца (`min(28px, ringWidth × 0.36)`), чтобы не «съедать» узкие секторы. Положение фиксировано за внешним краем кольца (стрелка направлена радиально наружу) — при любом `size`, включая `size=120/centerSize=24`, шеврон не уезжает внутрь сектора и не сливается с контентом. Покрыто unit-, интеграционными и e2e-тестами.
- Событие `select` теперь несёт `detail.coords` — координаты указателя в момент клика по пункту (`{ x, y }`, clientX/clientY). Третьим аргументом те же координаты передаются в `action`: `action(id, menu, coords)`. Существующие `action(id, menu)` продолжают работать.
- События `open`, `close`, `select` теперь несут `detail.menu` — экземпляр меню, для которого событие вызвано (`open`: `detail: { rect, menu }`; `close`: `detail: { menu }`; `select`: `detail: { id, menu }`). `action` пункта вызывается с двумя аргументами: `action(id, menu)`.
- `Pielet.closeAll()` — статический метод: плавно закрывает открытое меню без ссылки на экземпляр (no-op, если меню не открыто). Удобен для глобальных обработчиков.
- Исправление жизненного цикла: повторный `open()` уже открытого экземпляра молча заменяет runtime (без `close`-события), а финальное закрытие диспатчит `close` ровно один раз.
- `button` в конфиге задаётся текстовой константой: `'left' | 'middle' | 'right' | 'back' | 'forward'` (дефолт `'left'`). Отслеживаемая кнопка применяется и в hold-, и в click-режиме: меню выбирает/закрывается только по её отпусканию.
- `Pielet.BUTTONS` — статическое сопоставление текстовой константы и числового `PointerEvent.button` (удобно для фильтрации `pointerdown` вызывающим кодом).
- Исправление hold-режима: меню больше не «застревает», если вызывающий код открывает его кнопкой, не совпадающей с `config.button` (демо фильтрует открытие по отслеживаемой кнопке).
- `PieletItem.id` — опциональный строковый id пункта. Если не указан (или начинается с зарезервированного префикса `pielet-`) — генерируется автоматически при каждой нормализации в формате `pielet-<время>-<n>`.
- Событие `select` теперь несёт `detail: { id }`; `action` вызывается с id пункта первым аргументом.
- Событие `open` теперь несёт `detail: { rect }` — DOMRect-совместимый bounding rect видимой части меню в client-координатах (полный квадрат при целиком видимом меню, дуга при edge-reflow).
- Поддержка сенсорных устройств: демо больше не блокирует тач (`pointerdown` с `pointerType='touch'` открывает меню основной кнопкой; селект `button` на таче игнорируется, поскольку PointerEvent.button у тача всегда 0). В стили `.pielet` добавлен `touch-action: none` — drag-жест hold-режима не перехватывается браузером и не порождает `pointercancel`.

## 0.1.0 (2026-08-13)

Первый публичный релиз. Pielet — круговое контекстное меню без зависимостей.

**Возможности**

- `new Pielet(config)` / `open(x, y)` / `close()` — полный жизненный цикл; экземпляр — `EventTarget`.
- События `open`, `close`, `select` без payload; порядок при выборе: `select` → `close` → `action`.
- Мгновенное закрытие при scroll, resize окна, `visualViewport.resize`, выходе указателя за `closeDistance`.
- Одно открытое меню на страницу (модульный реестр активных runtime).
- Edge reflow: перераспределение секторов по наибольшей видимой дуге у краёв экрана, центр не смещается.
- `typeContent`: `text` (fit-to-box), `image`, `node`, `none` (разделитель).
- Режимы взаимодействия: `click` и `hold` (с выбором кнопки `button`).
- Hover-подсветка и клик по центру/зазору/пустому сектору закрывают меню без выбора.
- `clip-path` полигоны с настраиваемой точностью; ни Canvas, ни SVG, ни innerHTML.
- Тёмная тема через CSS custom properties (namespace `.pielet`).
- Пустой bundle: dist/pielet.js ~6.4 kB gzip, ноль импортов.
- Демо-страница (`npm run dev:demo`) и Playwright e2e для реального браузера.
