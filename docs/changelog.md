# Changelog

Все версии — фиксированные релизы (no rolling releases).

## Unreleased

**Возможности**

- Исправление жизненного цикла: повторный `open()` уже открытого экземпляра молча заменяет runtime (без `close`-события), а финальное закрытие диспатчит `close` ровно один раз.
- `button` в конфиге задаётся текстовой константой: `'left' | 'middle' | 'right' | 'back' | 'forward'` (дефолт `'left'`). Отслеживаемая кнопка применяется и в hold-, и в click-режиме: меню выбирает/закрывается только по её отпусканию.
- `Pielet.BUTTONS` — статическое сопоставление текстовой константы и числового `PointerEvent.button` (удобно для фильтрации `pointerdown` вызывающим кодом).
- Исправление hold-режима: меню больше не «застревает», если вызывающий код открывает его кнопкой, не совпадающей с `config.button` (демо фильтрует открытие по отслеживаемой кнопке).
- `PieletItem.id` — опциональный строковый id пункта. Если не указан (или начинается с зарезервированного префикса `pielet-`) — генерируется автоматически при каждой нормализации в формате `pielet-<время>-<n>`.
- Событие `select` теперь несёт `detail: { id }`; `action` вызывается с id пункта первым аргументом.
- Событие `open` теперь несёт `detail: { rect }` — DOMRect-совместимый bounding rect видимой части меню в client-координатах (полный квадрат при целиком видимом меню, дуга при edge-reflow).
- Поддержка сенсорных устройств: демо больше не блокирует тач (`pointerdown` с `pointerType='touch'` открывает меню основной кнопкой; селект `button` на таче игнорируется, поскольку PointerEvent.button у тача всегда 0). В стили `.pielet` добавлен `touch-action: none` — drag-жест hold-режима не перехватывается браузером и не порождает `pointercancel`.

## 0.1.0 (2026-08-13)

Первый публичный релиз. Pielet — круговое контекстное меню без зависимостей.

**Возможности**

- `new Pielet(config)` / `open(x, y)` / `close()` — полный жизненный цикл; экземпляр — `EventTarget`.
- События `open`, `close`, `select` без payload; порядок при выборе: `select` → `close` → `action`.
- Мгновенное закрытие при scroll, resize окна, `visualViewport.resize`, выходе указателя за `closeDistance`.
- Одно открытое меню на страницу (модульный реестр активных runtime).
- Edge reflow: перераспределение секторов по наибольшей видимой дуге у краёв экрана, центр не смещается.
- `typeContent`: `text` (fit-to-box), `image`, `node`, `none` (разделитель).
- Режимы взаимодействия: `click` и `hold` (с выбором кнопки `button`).
- Hover-подсветка и клик по центру/зазору/пустому сектору закрывают меню без выбора.
- `clip-path` полигоны с настраиваемой точностью; ни Canvas, ни SVG, ни innerHTML.
- Тёмная тема через CSS custom properties (namespace `.pielet`).
- Пустой bundle: dist/pielet.js ~6.4 kB gzip, ноль импортов.
- Демо-страница (`npm run dev:demo`) и Playwright e2e для реального браузера.
